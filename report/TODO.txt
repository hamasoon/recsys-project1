## A. [P1·신규] 4-b 동점 처리·정밀도에 따라 추천 순서가 크게 바뀜

현재 `ItemCF.recommend()`(main.py:146)는 반올림 전 원점수로 stable argsort 함.

원인: 평점이 하나인 사용자는 모든 후보 점수가 `r·s/(s+eps) ≈ r`. 후보 간 차이가 1e-8 수준이라 **float 노이즈가 순서를 결정**함. TF-IDF에서는 추천 대상 20명 중 9명의 top-20 전체가 같은 4자리 값(예: `4.0000` × 20)임.

구현 방식별 출력 일치 줄 수 (400줄 기준):

| 비교 | TF-IDF | semantic |
|---|---:|---:|
| 현재 코드 vs float64 원점수 정렬 | 183 | 346 |
| 현재 코드 vs float32 원점수 정렬 | 311 | 352 |
| float32 vs float64 (둘 다 원점수 정렬) | 183 | 343 |
| **반올림 후 정렬: 현재 코드 vs float64** | **400** | 365 |
| **반올림 후 정렬: float32 vs float64** | **399** | 362 |

- 반올림 후 정렬(`-round(score, 4)` 내림차순, 동점은 game_id 오름차순)만 정밀도와 무관하게 결과가 같음. PDF 3-b "계산 방법에 따른 0.01% 차이는 최종 결과에 영향 없음"과 모순되지 않는 유일한 해석.
- 반대로 채점 코드가 float64 원점수로 정렬한다면 반올림 후 정렬은 TF-IDF에서 182/400줄만 일치함. **해석이 확정되지 않았으므로 조교 확인 필요.**
- semantic은 분모가 0에 가까운 경우(top-20 내 최소 |분모| 3.8e-6)가 있어 반올림 후 정렬로도 완전히 일치하지 않음. 임베딩 자체가 환경마다 달라서(최댓값 906.6589 vs 906.9753) 이 부분은 정답과의 완전 일치가 불가능함. float64 계산이 참값에 가장 가까움.

## C. [P1·1차 #1, 방법 변경] ALPHA = 0.5 미튜닝 → 0.8 권장

PDF 4-c: `0 < α < 1`에서 0.5보다 성능이 좋은 값을 도출하고, 값과 방법을 보고서에 적어야 함. 현재 main.py:33과 main.typ:113은 TODO 상태.

누수 경고(1차 내용 유지): `score_rmse()`는 평가 대상 평점을 이력에서 제거하지 않음. 전체 `ratings`로 만든 모델에 `score_rmse(ratings)`를 호출하면 누수가 생김. 현재 호출하는 곳은 없음. 반드시 train만으로 `UserHistory`를 다시 만들어 평가해야 함.

1차가 권장한 closed-form 해 `α0 = Σ(s−t)(y−t) / Σ(s−t)²`는 원 점수 기준에서 semantic 이상치와 0 예측에 끌려 불안정함(이번 0.007~0.113, 1차 0.001~0.343). clip + fallback(B)을 적용하면 목적함수가 비선형이 되므로 closed-form 대신 grid search를 써야 함.

검증 절차: interaction 단위 무작위 20% 검증(`np.random.default_rng(seed).random(n) < 0.2`), train만으로 `UserHistory` 재구성, 두 모델 float64 정규화, α grid 0.01~0.99 (0.01 간격).

| seed | closed-form α0 (원 점수) | α=0.5 clip+평균 | 최적 α (clip+평균) | 최적 RMSE | warm 사용자만 RMSE (0.5 → 최적) |
|---:|---:|---:|---:|---:|---|
| 0 | 0.0285 | 1.1253 | 0.82 | 1.1224 | 1.3148 → 1.3067 |
| 1 | 0.0070 | 1.1252 | 0.80 | 1.1226 | 1.3136 → 1.3065 |
| 2 | 0.0639 | 1.1259 | 0.81 | 1.1231 | 1.3119 → 1.3041 |
| 3 | 0.0416 | 1.1251 | 0.80 | 1.1225 | 1.3115 → 1.3043 |
| 4 | 0.1129 | 1.1270 | 0.78 | 1.1247 | 1.3140 → 1.3078 |
| 5개 통합 | - | 1.1257 | **0.80** | **1.1231** | - |

- 개선 폭은 작지만(약 0.0026) 5개 분할 모두에서 일관됨. 다만 α를 고른 검증셋에서 잰 값이라 일반화 성능을 입증하지는 못함.
